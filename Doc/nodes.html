For Each

for_each

Loop over Mocap Collection outputs, checked BVH paths, or a numeric parameter range. The start node passes the active animation downstream.

Use and connections: Connect Collection output to source, route the animation through processing and Scene to Render, and connect Render to for_each_end.render. Use Run For Each, Stop, Loop Limit, Single pass, or Start at iteration. A comment wrapper groups the loop; each render must finish before the next iteration.

Workflow guide →
Inputs, parameters, buttons, and usage

Connections and result

Connect a Mocap Collection to source. Send the start node output through animation processing, Scene, and Render. Connect Render to the paired For Each End render input.

Parameters and options

ControlWhat it does
IterateCollection outputs respects the collection’s Checked only setting. Checked paths always uses checked files. Parameter range changes a numeric parameter instead of selecting takes.
Loop Limit0 / All visits every eligible input. A positive number caps the iterations run, including when starting partway through the list.
Single pass / iterationRuns one eligible iteration; numbering starts at 1. This overrides Loop Limit and counts eligible inputs, not the original collection row numbers.
Loop Start / start iterationStarts at a chosen eligible iteration and continues. Enabling it turns off Single pass.
Parameter / Count / First value / StepIn Parameter range mode, choose the parameter to vary, number of values, initial value, and increment.

Buttons and editing actions

ControlWhat it does
Run For EachStarts the loop and waits for each connected render to complete before advancing.
StopStops the running loop.
Create wrapperRecreates the comment wrapper and paired end node if the wrapper was deleted.

Using this node

  1. Load and check takes in Mocap Collection.
  2. Connect the render chain and its completion output to For Each End.
  3. Try Single pass first, then run the full range.

Putting a Render node inside the comment wrapper does not replace the required connection to the end node.
