Node Catalog

Detailed node descriptions are kept here so the main docs stay focused on general setup and workflows.

Choose a node from the left list to view only that node, or browse all nodes below.

Dedicated node pages: nodes with deeper documentation link to their own page. Start with image_gs_splat.

Core and Utility

note

Note tasks and text content with per-parameter controls.

node

Standard general-purpose parameter node.

append

Ordered input aggregation; can drive Gantt group order.

switch

Single-branch selection from multiple upstream nodes.

gantt_chart

Scheduling board with multi-note grouping, collapse state persistence, and CSV copy/paste transfer.

python

Run custom scripts in graph context.

output

Terminal collector for final graph output.

AI and Knowledge

local_server

Local server endpoint configuration.

llm_prompt

OpenAI or Ollama/DeepSeek model settings and response generation for Chatbot workflows.

chatbot

Conversation workflows with Database history, Voice Actor input, LLM Prompt runtime, and optional mediator_input.

database

Persistence layer for graph and chat data.

data_nexus

Folder-aware knowledge canvas for points, vault files, graph relationships, question and slide point types, review rings, references, and answer-to-question links.

skills

Local Skills library browser for human templates, agent templates, task guides, approval state, validation warnings, review diffs, and Sales Agent deck generation.

task

Workflow step controller that reads Skills, Data Nexus, and optional Mediator AI; checks readiness, writes questions, generates drafts, refreshes HTML, and indexes slides.

librarian

Document indexing, search, summarize, and analysis.

Automation, Voice, and Control

voice_actor

Speech-to-text and text-to-speech node with Auto Respond, Ask First, and Manual send modes.

audio_capture

Captures output device, input device, or application audio with backend, sample-rate, threshold, silence, and phrase controls.

translator

Translate incoming text or voice transcripts with language, style, and automatic translation controls.

Connect: Send text to text and connect an llm_prompt node to the matching input to choose the provider and model. The translated result leaves through text and can feed a Voice Actor for speech.

Use: Select From and To languages, choose Natural or Literal style, and enable Auto for new incoming text or click Translate manually.

openai_realtime_translate

Translate live microphone speech with spoken output and a live translation transcript.

Setup: Enter an OpenAI API key, select the model and voice, and set the source and target languages. This node captures microphone audio directly and requires the PyAudio and websockets dependencies.

Use: Click Listen to begin. Configure bidirectional translation or add a second language route, and adjust the silence interval for speech turns. The node exposes audio and text outputs.

minimax_tts_api

Generate speech audio from text through the MiniMax Speech API.

Connect: Feed the text input or enter text in the node. Connected text takes priority. Supply a MiniMax API key and choose a speech model and voice ID, including a custom voice ID when available.

Controls: Set speed, volume, pitch, output format, sample rate, and output folder. The generated file is available through audio and audio_path for playback or downstream audio effects.

mediator_agent

Agent profile layer and technical executor for direct voice workflows, Chatbot-origin tool handoff, and Sales Agent AI task review.

codex_sandbox

Future Mediator execution-policy node for Codex sandbox, approval, working directory, network, and output capture settings.

qubit_deck_controller

List or execute Qubit Deck actions from manual fields or Mediator JSON.

keyboard_sequence

Keyboard Auto Runner for timed key/action sequences with lead-in, hold time, delays, and injection mode.

serial_com

Stores COM port, baud, and timeout settings for serial/Pico HID automation paths.

3D, Rigging, and Scene Processing

import

Load mesh or splat assets.

fbx_import

Ingest and validate FBX rest geometry, capture pose, and animated pose roles for rigging workflows.

fbx_animation

Import an FBX animation clip with skeleton validation and a viewport preview.

Use: Choose an FBX in path, click Validate FBX Anim, and inspect the clip and skeleton summary before previewing it.

Connect: Feed the node into fbx_import through animated_pose for animation or capture_pose for a capture source, or connect it to Scene for playback. The Create Node name is fbx_animation; fbx_animation_import is an alias.

genx_video_mocap

Run GEN-X/GEM-X video mocap and create downstream BVH import nodes.

mocap_import

Import and validate BVH mocap clips with skeleton, frame, and clip summaries.

anim_retarget

Connect a mocap/FBX source to a target FBX rig with joint mapping, root controls, pose offsets, and preview options.

camera

Scene camera placement/control node.

light

Directional, point, spot, and area light setup with intensity, range, and shadow parameters.

instance

Create repeated scene instances.

copy_to_points

Copy source geometry onto point inputs with instancing and material/texture support.

primitive

Generate procedural primitive geometry.

curve

Create line, circle, or spiral curve scene assets.

modeler

Inspect model object names, hide/isolate submeshes, and save object/point/edge/face selection groups.

transforms

Apply translate/rotate/scale offsets in-chain.

ply_sequence

Sequence playback/control for PLY streams and splat frame workflows.

image_gs_splat

Download a URL or local image, run Image-GS, preview the generated Gaussian result in the node, and output a viewport-ready PLY splat. Open detailed page.

scene

Assemble and manage multi-asset scenes.

export_fbx

Export scene geometry to FBX.

export_fbx_animation

Export validated FBX rigs with skeletons, skinned meshes, animation ranges, FPS, and optional joint-scale curves.

export_obj

Export to OBJ/MTL.

Material setup and conversion utilities.

fx

Post-process and trail-style pipeline stage.

fx_splat_physics

Add motion lag, gravity, noise, and fading trails to animated skinned splats.

Connect: Feed skinned_splat_proxy into splats, then send the result to Scene. Physics follows the animated target positions while allowing controlled drift.

Controls: Choose a preset, then tune Follow, Drag, Velocity, Gravity Y, noise, substeps, and Max Lag. Trail and Glow add visual effects; Reset on timeline jumps resets the simulation when scrubbing beyond the Jump threshold.

fx_splat_fx

Apply audio-driven glow and traveling wave effects to Gaussian splats.

Connect: Supply a skinned splat proxy or a compatible splat-effects node to splats. Connect an audio source to audio or browse to an audio file, then use View to preview with the timeline.

Controls: Adjust audio gain, smoothing, threshold, and start offset, then tune glow intensity, radius, saturation, and wave strength, width, speed, and axis. This node is also available through the splat_fx and splat_glow aliases.

colorize

Recolor splats with a three-color ramp driven by their shape or height.

Connect: Feed a skinned splat proxy or compatible splat-effects chain into splats, then preview it in Scene or with View.

Controls: Choose Thickness, Density, Radius, Area, or Height Y as the metric. Set low, middle, and high colors, then adjust percentile limits, invert, gamma, and blend. splat_colorize and fx_splat_colorize are aliases.

fx_music_effects

Drive mesh displacement from an audio track, including animated character geometry.

Connect: Supply geometry to mesh and a sound source to audio, or select an audio file in the node. Use View to preview the deformation with timeline audio.

Controls: Set analysis gain, smoothing, threshold, and audio start offset. Displacement, maximum displacement, and outward-only movement control how far the surface responds to the sound.

wire

Wire and curve-based geometry path workflows.

groom_guides

Generate guide curves from a painted mask and source mesh.

groom_deform

Bind guide curves to FBX/retarget rigs and optionally hide the deformer geometry.

groom_guide_pose

Pose guide curves from animation frames with XPBD-style strand settings and optional GPU support.

groom_guide_sim

Simulate guides with frame, FPS, substep, stretch, bend, gravity, wind, and collider controls.

groom_guide_tube

Convert guide curves into tube geometry with radius ramp, subdivisions, caps, smoothing, and source-guide display.

skinned_volume_mesh

Generate skinned voxel collision meshes from rig contexts for grooming simulation and viewport collision.

skinned_splat_proxy

Generate skinned splat proxies from retargeted rigs, FBX imports, or guide tubes.

Media and Review

html_preview

In-node HTML rendering with a path input and PDF export for generated decks and other upstream HTML artifacts.

image_collection

Assemble and preview image sets.

video_player

Timeline playback and clip inspection.

youtube_downloader

Download a YouTube video as MP4, extract MP3 audio, and optionally save a Markdown transcript.

Use: Enter a video URL, choose an output folder, and enable transcript export with the preferred caption language when needed. Downloads and audio conversion use yt-dlp and FFmpeg; transcript availability depends on the video captions.

Outputs: mp4_path, mp3_path, and transcript_md. Connect the video to video_player for review or route the audio into the music and splat effects nodes.

minimax_h3_video

Generate video from a prompt and optional first/last images through a local MiniMax H3 runtime.

Setup: Use Setup Model to prepare the local checkpoint, choose the model folder and variant, and configure a running local H3 service URL. Generation requires both the checkpoint and the local service.

Connect: Inputs are prompt, first_image, and last_image. Choose duration, aspect ratio, resolution, and output folder, then click Generate. Outputs are mp4_path, task_id, and h3_status.

minimax_h3_api_video

Generate MiniMax H3 video through the cloud API using a prompt, frame images, or reference images.

Setup: Enter a MiniMax API key and select the API base, model, duration, aspect ratio, and resolution.

Connect: Use prompt with optional first_image and last_image in Image-to-video mode, or use reference_images in Reference-to-video mode. Reference images and first/last frames are separate modes. Outputs are mp4_path, task_id, and h3_api_status.

wan22_video

Run local Wan 2.2 TI2V-5B text-to-video or image-to-video generation and output an MP4.

Setup: Use Setup Wan and select the runtime and model folders. Connect prompt and optionally image, or fill in those fields directly.

Controls: Set a negative prompt, output size, frame count, seed, sampler, steps, guidance, and Image Change. CPU offload and text-encoder controls help manage GPU memory. Outputs are mp4_path and wan_status; connect the MP4 to Video Player for review.

render

Render sequence/export pipeline stage.

post_process

Apply image-sequence effects such as ordered dithering and produce an output frame pattern.

sequence_to_mp4

Encode image sequences to MP4 with FPS, codec, and bitrate settings.
