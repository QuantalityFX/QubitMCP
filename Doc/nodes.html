Node Catalog

Detailed node descriptions are kept here so the main docs stay focused on general setup and workflows.

Choose a node from the left list to view only that node, or browse all nodes below.

Show all nodes

Dedicated node pages: nodes with deeper documentation link to their own page. Start with image_gs_splat.

Core and Utility

note

Note tasks and text content with per-parameter controls.

node

Standard general-purpose parameter node.

append

Ordered input aggregation; can drive Gantt group order.

switch

Single-branch selection from multiple upstream nodes.

gantt_chart

Scheduling board with multi-note grouping, collapse state persistence, and CSV copy/paste transfer.

python

Run custom scripts in graph context.

output

Terminal collector for final graph output.

AI and Knowledge

local_server

Local server endpoint configuration.

llm_prompt

OpenAI or Ollama/DeepSeek model settings and response generation for Chatbot workflows.

chatbot

Conversation workflows with Database history, Voice Actor input, LLM Prompt runtime, and optional mediator_input.

database

Persistence layer for graph and chat data.

data_nexus

Folder-aware knowledge canvas for points, vault files, graph relationships, question and slide point types, review rings, references, and answer-to-question links.

skills

Local Skills library browser for human templates, agent templates, task guides, approval state, validation warnings, review diffs, and Sales Agent deck generation.

task

Workflow step controller that reads Skills, Data Nexus, and optional Mediator AI; checks readiness, writes questions, generates drafts, refreshes HTML, and indexes slides.

librarian

Document indexing, search, summarize, and analysis.

Automation, Voice, and Control

voice_actor

Speech-to-text and text-to-speech node with Auto Respond, Ask First, and Manual send modes.

audio_capture

Captures output device, input device, or application audio with backend, sample-rate, threshold, silence, and phrase controls.

mediator_agent

Agent profile layer and technical executor for direct voice workflows, Chatbot-origin tool handoff, and Sales Agent AI task review.

codex_sandbox

Future Mediator execution-policy node for Codex sandbox, approval, working directory, network, and output capture settings.

qubit_deck_controller

List or execute Qubit Deck actions from manual fields or Mediator JSON.

keyboard_sequence

Keyboard Auto Runner for timed key/action sequences with lead-in, hold time, delays, and injection mode.

serial_com

Stores COM port, baud, and timeout settings for serial/Pico HID automation paths.

3D, Rigging, and Scene Processing

import

Load mesh or splat assets.

fbx_import

Ingest and validate FBX rest geometry, capture pose, and animated pose roles for rigging workflows.

genx_video_mocap

Run GEN-X/GEM-X video mocap and create downstream BVH import nodes.

mocap_import

Import and validate BVH mocap clips with skeleton, frame, and clip summaries.

anim_retarget

Connect a mocap/FBX source to a target FBX rig with joint mapping, root controls, pose offsets, and preview options.

camera

Scene camera placement/control node.

light

Directional, point, spot, and area light setup with intensity, range, and shadow parameters.

instance

Create repeated scene instances.

copy_to_points

Copy source geometry onto point inputs with instancing and material/texture support.

primitive

Generate procedural primitive geometry.

curve

Create line, circle, or spiral curve scene assets.

modeler

Inspect model object names, hide/isolate submeshes, and save object/point/edge/face selection groups.

transforms

Apply translate/rotate/scale offsets in-chain.

ply_sequence

Sequence playback/control for PLY streams and splat frame workflows.

image_gs_splat

Download a URL or local image, run Image-GS, preview the generated Gaussian result in the node, and output a viewport-ready PLY splat. Open detailed page.

scene

Assemble and manage multi-asset scenes.

export_fbx

Export scene geometry to FBX.

export_fbx_animation

Export validated FBX rigs with skeletons, skinned meshes, animation ranges, FPS, and optional joint-scale curves.

export_obj

Export to OBJ/MTL.

Mesh, Materials, and Grooming

uv_unwrap

UV workflow stage.

normals

Smooth mesh normals and cache an updated OBJ for downstream texture, mask, and scene workflows.

texture

Base texturing stage.

texture_pro

Expanded texture processing controls.

texture_layer

Layered texture compositing.

material

Material setup and conversion utilities.

mask

Paint foreground/background mesh masks with brush, falloff, invert, clear, and preview controls.

split_volume / volume_selector

Filter/split geometry by volume.

fx

Post-process and trail-style pipeline stage.

wire

Wire and curve-based geometry path workflows.

groom_guides

Generate guide curves from a painted mask and source mesh.

groom_deform

Bind guide curves to FBX/retarget rigs and optionally hide the deformer geometry.

groom_guide_pose

Pose guide curves from animation frames with XPBD-style strand settings and optional GPU support.

groom_guide_sim

Simulate guides with frame, FPS, substep, stretch, bend, gravity, wind, and collider controls.

groom_guide_tube

Convert guide curves into tube geometry with radius ramp, subdivisions, caps, smoothing, and source-guide display.

skinned_volume_mesh

Generate skinned voxel collision meshes from rig contexts for grooming simulation and viewport collision.

skinned_splat_proxy

Generate skinned splat proxies from retargeted rigs, FBX imports, or guide tubes.

Media and Review

html_preview

In-node HTML rendering with a path input and PDF export for generated decks and other upstream HTML artifacts.

image_collection

Assemble and preview image sets.

video_player

Timeline playback and clip inspection.

render

Render sequence/export pipeline stage.

post_process

Apply image-sequence effects such as ordered dithering and produce an output frame pattern.

sequence_to_mp4

Encode image sequences to MP4 with FPS, codec, and bitrate settings.
