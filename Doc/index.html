Qubit Manual

Qubit is a node‑based workflow tool with a built‑in 2D graph editor and a 3D viewport for scene assembly and asset review. This manual covers daily use and high‑level development concepts.

Overview

What Qubit does: build workflows by connecting nodes, preview assets, and run text / AI / 3D pipelines from a single canvas.
  • Node graph editor with wires, grouping, and info cards.
  • 3D viewport with camera tools, grid, and transform gizmos.
  • AI/LLM nodes for prompt pipelines and chat workflows.
  • Scene nodes for assembling multiple imports into a 3D view.
  • Hotkeys and settings are fully configurable.

Quick Start

  1. Open Qubit and choose File → Open or Open Recent.
  2. Create a node with Create → Node or press Tab.
  3. Connect nodes by dragging from one node’s output to another’s input.
  4. Select a node to view its details in the Info panel.
  5. Use the 3D viewport buttons to frame, toggle grid, or capture snapshots.

UI Tour

Top Bar

  • File: New, Open, Open Recent, Save, Save As.
  • Create: Create new nodes.
  • Settings: LLM scale and viewport tuning.
  • Hotkeys: Edit keyboard and mouse bindings.
  • 2D/3D: Switch between 2D, 3D, and split views.
  • Frame and Logs buttons.

Main Areas

  • Graph Canvas (2D): nodes and wires.
  • 3D Viewport: assets, grid, gizmos.
  • Info Panel: node details and controls.

Workflows

  • Workflows are saved as JSON files.
  • Use Open Recent to quickly return to prior work.
  • Saving preserves node layout, parameters, and settings.

Graph Basics

Mouse Controls

  • Left‑click: select nodes / start wires.
  • Middle‑drag: pan the canvas.
  • Right‑drag: zoom.
  • Alt + Left‑click on a wire: remove wire.

Selection & Editing

  • Click a node to open its Info Card.
  • Copy/paste nodes with standard shortcuts.
  • Group selections into comment frames.

3D Viewport

  • Used for Import and Scene nodes.
  • Frame the view to fit assets.
  • Wireframe and grid toggles are available.
  • Camera orbits, pans, and zooms around a focus target.

Gizmos & Transforms

  • Translate (T), Rotate (R), Scale (E).
  • World/Local space toggle for transform orientation.
  • Scene Outliner drives which asset the gizmo controls.
  • Undo/redo for transform changes.

Viewport Controls

  • Grid and Grid FX toggles.
  • Wireframe toggle (W).
  • Gizmo visibility toggle for clean snapshots.
  • Snapshot button for captures.

Settings

  • LLM Scale: scales LLM node UI footprint.
  • Pan Base / Pan Exp / Pan Boost: viewport pan feel.
  • Gizmo Zoom: zoom sensitivity in large scenes.
  • Debug Log: enable/disable debug logging.

Node Catalog

Grouped by purpose. Each node exposes inputs/parameters in its Info Card.

Core

  • Node: general‑purpose text node.
  • Note: formatted note with inline display selection.
  • Output: terminal node for collecting results.

Logic

  • Append: merge upstream text in UI order; preview and save JSON.
  • Switch: select active branch (toggle in Info Card).

AI / Knowledge

  • LLM Prompt: send prompts to OpenAI or Ollama; supports files and temperature.
  • Chatbot: chat UI that uses LLM Prompt + Database history.
  • Database: Mongo‑based project/history store.
  • Librarian: document search and summarization (query, docs_dir, mode, top_k).

Media

  • HTML Preview: display HTML content.
  • Image Collection: build a tiled image mosaic.

3D / Scene

  • Import: load 3D assets and preview in viewport.
  • Scene: assemble multiple imports, manage visibility and transforms.
  • Scene Outliner: view assets, rename, and toggle visibility.

Tools

  • Python: edit and run Python scripts with graph inputs.
  • 3DGen: optional generation workflow (external tool).

Common Pipelines

Scene Assembly

  1. Create Import nodes for each asset.
  2. Connect imports into a Scene node.
  3. Click View Scene to load into the 3D viewport.
  4. Use the Scene Outliner to select and transform assets.

LLM Workflow

  1. Create LLM Prompt node and set provider/model.
  2. Optional: connect Database to persist history.
  3. Use Chatbot for interactive conversations.
  4. Append + Output to merge and save responses.

Troubleshooting

  • If a hotkey doesn’t work, open Hotkeys and verify the binding.
  • If viewport feels slow, reduce Grid FX or Wireframe usage.
  • Use Logs for debugging and enable Debug Log only when needed.

Developer Guide (High‑Level)

  • Node system: Qubit loads node definitions at startup. Each node can define ports, UI, and Info Card actions.
  • Extensibility: New nodes can be registered as plugins without modifying core UI.
  • Hotkeys: Stored in a JSON file and editable in‑app.
  • Workflows: Saved as JSON; include nodes, links, params, and viewport settings.
  • Logs: Debug logs are written only when enabled.
